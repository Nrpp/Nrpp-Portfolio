# Nrpp-Portfolio

My personal website, made to look like a little desktop OS. It has "windows" you can close, a sidebar meny, a sticky note and a fake "Lab" panel showing what I'm currently working on (and what's currently broken :)). Programed in HTML, CSS and JavaScript.

## Features
- "Welcome" window with a little status panel (what I'm building, what I'm learning, etc.)
- Featured Projects window with cards for my other projects
- Sidebar menu (Home, Proyects, Lab, Now, Blog, Terminal, Secrets)
- A sticky note with my current '/now' list
- A Lab window showing the status of different things I'm currently messing with
- Windows can be closed with the X button
- Works on mobile too

## How to run it

You can just go to nrpp.github.io and see it there.
